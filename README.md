# SubseçãoPRO · App web

Aplicativo web do **SubseçãoPRO**, plataforma digital para subseções da OAB. Os dados deste repositório são fictícios ("OAB Cidade Exemplo").

## Funcionalidades

- **Início** com novidades da subseção e redes sociais
- **Diretório de advogados** com perfil de cada inscrito
- **Serviços** da subseção, com página de detalhe
- **Reserva de salas** com agenda
- **Clube de benefícios** com parceiros
- **Eleições:** acompanhamento do processo eleitoral
- **Assistente de IA** para triagem e dúvidas
- **Perfil do advogado**, configurações, termos e política de privacidade (LGPD)

## Stack

TanStack Start (React 19, SSR) · TypeScript · Tailwind CSS v4 · shadcn/ui · TanStack Query

Faz parte do ecossistema SubseçãoPRO, junto com o [painel administrativo](https://github.com/marcosvpantoja/subsecaopro-painel-admin), a [API](https://github.com/marcosvpantoja/subsecaopro-api) e a [IA de triagem](https://github.com/marcosvpantoja/subsecaopro-ia-triagem).

## Como rodar

```sh
npm install
npm run dev
```
